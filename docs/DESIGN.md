# Tally

Read, locate, act.

Tally aligns navigation and messages on a tighter rhythm. Flat surfaces, quiet rules and tabular timestamps make dense conversations easier to scan. Amber is reserved for selection and action.

## Geometry

3px corners, continuous ruled columns, compact channel rhythm, underlined tabs and square-edged composer.

## Typography and motion

Discord's own font stack and user font size remain intact. Hierarchy comes from grouping, spacing and weight; code alone uses the native monospace. Native icons remain identifiable and user roles retain their colors. State changes are immediate; no theme animations. Reduced motion disables authored transitions.

## Decisions

No photographs, external fonts or icon libraries. An original geometric logo is documentation-only. No decorative dashboard labels, invented telemetry or cosmetic controls. Rules organize conversations; message typography remains controlled by Discord.
