# Credits and research

Research checked 2026-09-11. Original theme CSS and geometric logo: ussmarines, developed with Codex. No third-party theme code, photographs, fonts or replacement icons are bundled. Discord owns its native content and icons. css-tree (development dependency) is MIT licensed.

## Technical sources

- [BetterDiscord structure](https://docs.betterdiscord.app/themes/introduction/structure): JSDoc metadata and a single vanilla CSS distribution.
- [Selectors](https://docs.betterdiscord.app/themes/tutorials/selectors): specificity and localized selectors. Its Chromium 108 note is historical; the inspected client runs Chromium 148.
- [Accessibility](https://docs.betterdiscord.app/themes/concepts/accessibility) and [performance](https://docs.betterdiscord.app/themes/concepts/performance): respect user settings and bound expensive effects.
- [Configuration](https://docs.betterdiscord.app/themes/tutorials/user), [remote imports](https://docs.betterdiscord.app/themes/tutorials/remote), [distribution](https://docs.betterdiscord.app/themes/publishing/distribution).
- [Theme guidelines](https://docs.betterdiscord.app/themes/publishing/guidelines): preserve functionality. These repositories do not claim acceptance into the BetterDiscord catalogue; its authorship rules differ from mere file compatibility.
- [Vencord source](https://github.com/Vendicated/Vencord) and [FAQ](https://vencord.dev/faq/): common CSS format and troubleshooting.

## Visual references

- [Fluent 2 elevation](https://fluent2.microsoft.design/elevation): depth used for hierarchy.
- [Material 3 Expressive](https://design.google/library/design-notes-material-3-expressive-liam-spradlin): shape serving usability.
- [Spectrum 2](https://s2.spectrum.adobe.com/): adaptive density and contextual components.
- [Carbon color](https://carbondesignsystem.com/guidelines/color/overview/): layered neutral surfaces.
- [Apple Liquid Glass](https://www.apple.com/newsroom/2025/06/apple-introduces-a-delightful-and-elegant-new-software-design/): material reserved for navigation, not message content.
- [Rhea](https://ui.shadcn.com/docs/changelog/2026-05-rhea): density is component design, not a global spacing multiplier. Luma and Sera are visual references only; no framework is imported.

Warm minimalism informs Clayloom's palette; soft elevation its input hierarchy; bento influences stop at functional grouping. Editorial minimalism informs Tally's alignment and restrained accent. Spatial layering informs Parhelion's separated planes. None reproduces a reference application's layout.
