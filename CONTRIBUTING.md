# Contributing

Keep each change scoped to a surface or token responsibility. Run npm ci, npm run build and npm test; include the generated distribution in the same change. Check both Discord appearance modes and record client versions. A CSS parse is not a visual test. Never include account data or private screenshots. Do not add plugins, remote assets or exact hashed class selectors without documenting the reason and fallback. Preserve native keyboard behavior, semantic status colors and user font preferences.
